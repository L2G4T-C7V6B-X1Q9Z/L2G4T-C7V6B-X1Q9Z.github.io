AnkiVoice

Hands-free Anki flashcard review for commuting, exercising, and any hands-busy activity.

In Development React Native TypeScript Expo AnkiConnect

Concept

AnkiVoice is a mobile app that lets you review Anki flashcards entirely without touching your phone. It's designed for situations where your hands are occupied — driving, running, cooking, walking between hospital floors — but your brain is free to study.

The system supports three input methods that can be used independently or combined: voice commands, pocket tap detection, and traditional on-screen buttons.

Input Methods

Voice Commands

Wake word detection ("Anki") followed by natural commands: "flip it", "got it", "nope", "easy", "skip". Includes fuzzy matching for phonetic variations in noisy environments.

Pocket Tap Detection

Accelerometer + gyroscope sensor fusion detects intentional taps through fabric while filtering out walking/running movements. Single tap shows answer, double tap marks good, triple tap marks again.

Two Review Modes

Discrete: give simple show/rate commands. Non-discrete: speak your answer aloud and the system evaluates it against the card's answer using similarity comparison.

Driving Mode

Extra-large text, simplified UI, and audio-first interaction. Cards are automatically read aloud via text-to-speech. Designed for safe use during commutes.

Sync System

AnkiVoice connects to Anki Desktop via the AnkiConnect API. The sync system is offline-first: reviews are queued locally and synced when a connection is available. The queue uses exponential backoff retry logic and batch syncing to handle unreliable network conditions.

  • Fetches decks and due cards from Anki Desktop
  • Processes cloze deletions for audio readback
  • Submits card reviews with correct intervals
  • Persists review queue to local storage for crash recovery

Tap Detection

The tap detector is the most technically interesting component. It fuses accelerometer and gyroscope data to distinguish intentional taps from ambient motion. The calibration process (5 taps) establishes a baseline for the user's phone placement and typical tap force.

  • Multi-tap detection: single, double, triple, and long-press
  • Walking pattern filtering using periodic motion analysis
  • Sensitivity calibration adapts to phone case thickness and pocket material
  • Debounce logic prevents accidental triggers

Tech Stack

  • Frontend: React Native with Expo Router, TypeScript, Zustand for state
  • Voice: Web Speech API (STT), Expo Speech (TTS), fuzzy string matching
  • Sensors: Expo Sensors (accelerometer + gyroscope), custom fusion algorithm
  • Sync: AnkiConnect HTTP API, AsyncStorage persistence, batch operations
